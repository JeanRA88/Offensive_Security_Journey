# Offensive_Security_Journey

Welcome to my personal cybersecurity learning repository. This repo is a collection of my notes, walkthroughs, tools, and methodologies as I pursue a career in Red Teaming and prepare for the OSCP certification.

## 🔥 What's Inside

- 🔐 Methodologies for recon, enumeration, exploitation, and privilege escalation
- 🧠 Cheatsheets for Nmap, privilege escalation, web testing, etc.
- 💣 Walkthroughs of Hack The Box, TryHackMe, and OffSec Proving Grounds boxes
- 🎯 Progress tracking and OSCP preparation notes

## 📁 Repo Structure

/cheatsheets      → Quick reference for tools and techniques

/walkthroughs     → Detailed write-ups of CTF boxes and labs

/oscp-notes       → My roadmap and notes for PEN-200/OSCP

/tools.md         → My favorite tools and when to use them

/methodology.md   → My red teaming workflow

## 💡 Why This Repo?

Documenting my journey helps me:
- Retain and reinforce knowledge
- Share insights with others in the field
- Build a portfolio for future cybersecurity roles
